\section{Evidence and reproducibility}\label{app:repro}

Code, experiments, and the Lean development are in the public repository \url{https://github.com/ioannist/six-birds-currency}. Every numerical result in Section~\ref{sec:lab} is read from the receipts under \path{review/}, with one exception: the drive-parameter ranks of the ladder, which \path{scripts/make_paper_figures.py} computes directly (checking the fine-level value against the receipt) and writes to \path{paper/figures/ladder_family_rank.csv}. The same script draws every figure from these files. Experimental settings are the default parameters of the experiment scripts.

\paragraph{Regenerating the evidence.} In an environment with the Python dependencies declared in \path{pyproject.toml},
\begin{center}
\small
\begin{tabular}{l}
\texttt{PYTHONPATH=src MPLBACKEND=Agg python3 scripts/math\_review\_checks.py}\\
\texttt{PYTHONPATH=src:scripts python3 scripts/make\_paper\_figures.py}\\
\texttt{PYTHONPATH=src python3 -m pytest -q}\\
\texttt{cd lean \&\& lake build \&\& lake env lean CheckAxioms.lean}
\end{tabular}
\end{center}
The first command reruns all five experiments with their fixed designs. It writes one summary table per experiment and a receipt, \path{numerical_receipt.json}, that records the commands, the SHA-256 hashes of the selected Python and Lean source files, and the headline values. The test suite (63 tests) includes regression tests for each mathematical edge case discussed in the paper: infinite empirical audits, singular path mass, minimum-cost and slack budgets, infinite likelihood maximizers, cycle-rank counterexamples, and the packaging bound. \path{review/validation_receipt.json} records a passing run of the tests, the linter, the Lean build, and the axiom check.

\paragraph{Design choices.} All experiments use fixed, prespecified designs and report every outcome. The path-audit experiment draws one sample of fixed size per seed. The proxy experiment uses the requested design seed and a single proxy permutation for all samples, and records its predeclared criteria whether or not they hold. The ladder construction is deterministic, so its seed labels are repetitions. Numerical roots are floating-point approximations; each root of the budget solver is reported with the cost it actually achieves. Stationary laws are computed by an eigenvector method in the ladder and packaging experiments, and by lazified power iteration elsewhere (including stationary-conditional lumping when no stationary law is supplied); either way they are accepted only after a stationarity-residual check. None of the computations is an exact or interval-arithmetic certificate.
